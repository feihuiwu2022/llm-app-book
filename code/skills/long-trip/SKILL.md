# 长途出行前检查

按顺序做完下面三步，再给用户一份汇总。

1. 调用 get_tire_pressure 读取四个轮胎的胎压。
2. 调用 search_manual 查"胎压标准值"，逐个轮胎与标准对比；任何一个低于报警线都要明确提醒，不要只报平均值。
3. 调用 set_ac_temperature 把空调预设为 22 度。

汇总格式：先说能不能出发，再列出需要处理的问题，每个问题一行。
电量方面提醒用户：手册建议长途出行前充至百分之一百。
