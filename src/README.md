# 前言

这是开源知识库系列的第二卷。第一卷讲模型内部，本卷讲模型外面怎么搭系统：RAG、微调、工具调用、Agent 各自补 LLM 的哪块短板，怎么组合。

写法是掰开揉碎：从具体例子和实物形态讲起，结论给出可复算的过程。

全书八篇二十八章，都挂在第 1 章的那张表上：

| 篇 | 章 | 讲什么 |
|---|---|---|
| 一 地图 | 01 到 03 | 三个词的关系、一次调用的解剖、四个短板怎么测 |
| 二 改上下文 | 04 到 10 | 提示工程、RAG、GraphRAG 与 KAG、CAG、记忆 |
| 三 改模型 | 11 到 12 | 微调、LoRA、蒸馏，以及和 RAG 怎么选 |
| 四 行动 | 13 到 15 | 函数调用、MCP、代码执行与结构化输出 |
| 五 推理与控制流 | 16 到 18 | 思维链、ReAct、规划与反思 |
| 六 Agent 系统 | 19 到 22 | 主循环、Agentic RAG、上下文管理、多 Agent |
| 七 工程化 | 23 到 26 | 评测、可观测、安全、成本与延迟 |
| 八 选型方法论 | 27 到 28 | 决策树和三个案例 |

标 ▶ 的章节在仓库 `code/` 目录下有可运行的配套代码，只用 Python 标准库。代码里的模型默认是写死规则的替身，用来离线演示流程；书中凡是来自替身或假设单价的数字都有注明，请换成你自己的模型和价格复算。

从[第 1 章](ch01-llm-rag-agent.md)开始；想直接做选型，可以先看[第 27 章](ch27-decision-tree.md)。全书规划见仓库根目录的 `BLUEPRINT.md`。
